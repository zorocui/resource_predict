# 预测准确性统计与佐证

页面入口为顶部“预测准确性”。它与扩缩容建议置信度、预测上界覆盖率、调配成效分别统计。主要指标是明确容差下的达标率，不能用置信度分数或 `100%-MAPE` 替代。

## 三个独立入口

| 来源 | 使用的数据 | 证据边界 |
| --- | --- | --- |
| 预测兑现评估 realized | 当时冻结的入选模型预测，到期后匹配的同口径真实观测 | 只评价当时入选模型，不能据此公平比较所有模型；没有观测则不计准确率 |
| 独立历史测试 holdout | 新预测运行时冻结的全部候选模型外层测试预测、标签、时间和选模依据 | 仅接受独立测试及有效时间边界；标签来自预处理历史序列，可能含模拟数据，不等同于生产实测 |
| 旧报告参考 legacy | 已有 forecast_error_report.json 原始汇总误差 | 不重建预测点、不追认独立性、不推断原单位、不提供容差达标率 |

旧报告中有 `evaluation_role` 也不等于该入口已经核验逐点证据。没有新账本时显示真实空态，旧误差行数不是有效预测点数。不会用当前监控重构历史预测，也不会以新模型重算曲线冒充当时结果。

## 量化口径

对每个有效配对点，误差为 `预测值-实际值`。百分比利用率序列将0..1比例乘100展示：预测0.64、实际0.60，页面显示64%、60%，误差4个百分点（pp）。Request利用率可以超过100%，不会截断。

```text
MAE = 平均(|预测-实际|)
RMSE = sqrt(平均((预测-实际)^2))
±5pp点达标率 = |误差|≤5个百分点的有效配对点数 / 有效配对点数
±10pp点达标率 = |误差|≤10个百分点的有效配对点数 / 有效配对点数
低估比例 = 预测值<实际值的有效配对点数 / 有效配对点数
到期观测完整率 = 有效配对点数 / 全部到期选中点数
```

P95绝对误差采用nearest-rank：有效绝对误差排序后第 `ceil(0.95×N)` 项。±5pp/±10pp包含边界，是明确的规则容差，不是行业统一准确率要求，更不是相对误差5%/10%。绝对用量只展示cores/GiB误差，上述百分点达标率为null。

除按点汇总，还提供等权达标率：先计算各资源组的达标率，再等权平均；容器层按资源ID+容器名分组。它能防止预测点较多的资源主导结果。CPU、内存、磁盘、模型、资源/容器层、Request/Limit及单位分别成组，不能把异质误差直接相加或平均。

演算示例（不是生产实测）：10000个到期选中预测点中，9600个有有效观测，其中8832个误差≤5pp，则点达标率为92%，观测完整率96%。截图和报告必须同时保留这两个分母，不能只报“准确率92%”。

## 时间、重复预测与筛选

兑现提前量以 `target_ms-issued_ms` 划分0–1h、1–6h、6–24h、>24h；非正/缺失提前量单独为unknown。issued_ms沿用现有留档批次/生成时间代理，不保证等于前端实际发布可见时刻。旧兑现JSON报告仍以数据截止时间划分，和此页面口径不同，不能直接拼接两个报告的桶。

兑现去重以资源类型、资源ID、容器、指标、原始单位、目标时刻、提前量桶为组，固定取最新留档版本，批次和ID作为稳定决胜条件。先去重，再按模型筛选；即使最新版本缺观测，也不会挑误差更好的旧版本。`candidate_points`和`duplicate_points`是模型筛选前数量，`model_filtered_points`说明选中版本被模型筛选排除的数量。

历史测试提前量以 `target_ms-test_train_end_ms` 计算；每个候选模型分别保留同目标/同桶最近训练截止的测试版本，再以留档时间决胜。导入时检查独立测试角色、训练截止早于目标、测试边界一致、选模验证和路由边界没有使用测试段；失败预测保留真实测试标签和失败标记。

页面默认资源层，容器层单独查询。时间范围按目标时刻筛选，含开始、不含结束，输入框使用浏览器本地时区。旧报告没有逐点目标时刻或可比提前量，设置这些筛选后不会返回无法核验的旧行。

## 完整性和排除项

| 状态 | 含义 |
| --- | --- |
| matched | 有效、同口径、具备来源的配对，参与误差与达标率 |
| awaiting_target | 尚未到目标时刻 |
| awaiting_observation | 兑现预测到期但缺有效实测，包括不认可的mock观测来源 |
| missing_provenance | 来源或独立性依据不足 |
| not_future_at_publication | 目标不晚于留档/数据截止，不能作为事前预测 |
| nonfinite_observation | 实测无效，或冻结测试标签缺失/非有限；不能补成0 |
| invalid_prediction | 预测失败或预测数值无效 |
| basis_mismatch | 规格或归一化口径不同 |
| unsupported_unit | 单位无法核验 |

冻结测试标签缺失不会显示为“等待未来观测”。导出保留原始 `skip_reason`、来源、归一化依据和测试诊断，便于区分原因。非matched行即使有一个实际数值，也不能当作同口径有效实际；对照图只画有效实际。

当前页对照图仅显示同资源、容器、模型、批次和单位的离散点，并显示±5pp容差区；不会将空档或不同预测批次连成连续曲线。全量材料使用逐点CSV或报告快照。

## 数据流程与存储

新预测在worker中暂存 `_accuracy_holdout`，从已经计算的外层测试结果取值，不增加模型训练。`forecast_history/*.jsonl.gz` 新增 `holdout_forecasts`；归档之后、合并/输出当前详情之前移除临时字段，不把y_train/y_test复制进charts_forecast。

现有 `forecast_realized.sqlite3` 增加 `holdout_curves` 和 `holdout_points`，与批次保留期级联清理；未来预测仍用curves/points。整个批次导入原子提交，损坏批次不能标记为导入成功。新增按目标时间的索引，评分写入启用WAL；读取会话只读、固定事务快照，统计/P95在SQLite完成，逐点分页和导出不会一次把所有点加载到Python内存。大型查询仍随筛选范围增加计算量，应按目标日期、提前量和指标收窄范围。

默认留档保留7天，未评分不会当零误差。VM需要数据源提供真实 `observation_evidence` 才能形成兑现配对；mock或仅有旧误差报告时不能证明生产准确率。历史独立测试和兑现评估的来源、时间及单位不能混淆。

## 导出与长期快照

- **汇总CSV**：当前完整筛选范围的分组指标；旧报告入口导出原始汇总参考行。
- **逐点CSV**：去重并筛选后全部选中点，不限当前页，包含有效/待评/排除状态；旧报告没有此功能。
- **保存报告快照**：明确点击后，将同一个只读事务中的筛选、汇总、全部选中点和去重前候选流式保存为ZIP。完成后才原子发布下载链接，不发布半成品。
- **打印**：打印当前已查询的筛选、统计和可见明细/图表。打印只覆盖当前页面；全量证据应同时保存ZIP，不能把分页截图称为全部明细。

快照在输出根目录 `accuracy_snapshots/<32位ID>.zip` 独立保存，不受7天账本保留期影响，也不会自动删除。用户应按长期审计要求备份、控制存储和保存下载包。

普通快照包含：

```text
manifest.json           # 口径、筛选、记录数、每个文件的SHA256与字节数
report.json             # 冻结时刻完整汇总、完整性、第一页样本和筛选
summary.csv             # 分组指标
points.csv              # 全部选中点，展示单位
points.jsonl.gz         # 全部选中点及来源/口径，展示单位
candidates.jsonl.gz     # 去重与模型筛选前的候选，保留原单位与有效性标记
```

旧参考快照使用 `legacy_rows.csv` 和 `legacy_rows.jsonl.gz`，point_count=0；不能把参考行数理解为预测点数。

JSON/CSV的达标率与完整率是0..1比例，页面乘100显示百分比；`percentage_points`单位的选中预测/实际/误差已经乘100。候选文件中 `predicted_native`、`actual_native` 保持原始单位，可据固定决胜规则重新验证去重与统计。无效原数值用null及finite标记保存，不将NaN/Infinity写成标准JSON。

下载响应给出整个ZIP的SHA256；manifest给出包内文件SHA256。它证明文件一致性，不是第三方真实性签名。截图需保留来源、目标时间范围、提前量、容差、有效点数、资源数和观测完整率；不能只截“准确率”一个数字。

## API

| 方法 | 地址 | 作用 |
| --- | --- | --- |
| GET | `/api/forecast-accuracy` | 分组统计、完整性和逐点分页 |
| GET | `/api/forecast-accuracy/export.csv?kind=summary` | 同筛选汇总CSV |
| GET | `/api/forecast-accuracy/export.csv?kind=points` | 同筛选全部选中点CSV |
| POST | `/api/forecast-accuracy/snapshots` | JSON筛选条件，冻结报告；成功201 |
| GET | `/api/forecast-accuracy/snapshots/<id>/download` | 下载已完成ZIP |

共享筛选：source=realized/holdout/legacy、resource_type、level=resource/container、metric、model、horizon、q（资源ID子串）、from_ms/to_ms（整数epoch毫秒）。默认realized/resource。列表另支持page≥1、page_size=1..200；CSV和快照忽略分页。非法参数400、缺少快照404、账本/存储错误503；空账本返回真实空结果，不创建假证据。
