# 预测准确性统计与佐证

页面入口为顶部“预测准确性”。它与扩缩容建议置信度、预测上界覆盖率、调配成效分别统计。主要指标是明确容差下的达标率，不能用置信度分数或 `100%-MAPE` 替代。

## 当前默认：轻量历史测试准确率

打开页面直接读取 `forecast_accuracy_summary.json`，没有必填条件或评估来源切换。每次预测对本轮新生成资源的实际选用模型计算独立历史测试汇总，自动覆盖对应 scope 的上一份汇总；增量预测仅代表本轮重算范围。K8S 有容器预测时优先统计容器，避免与 Workload 汇总重复计数。

准确率 = 误差不超过 ±5 个百分点的有效点数 / 有效测试点数。无效值、非独立测试不计入分母；绝对核数/GiB等非比例指标仅报告原单位MAE，不混入百分点达标率。无有效点显示“—”，不显示0%。测试仍基于预处理历史数据，不等于未来兑现结果。

页面显示资源数、有效点、达标点、测试时间、各scope更新时间及前100条汇总；CSV包含全部汇总行和统计口径，可截图或打印保存PDF作为材料。只保存每条曲线的计数和误差汇总，不保存逐点数组。

升级后需要完成一次新预测生成新汇总；单纯拉取数据不会生成历史测试准确率。旧误差报告没有达标点计数，不伪造回填。逐点留档生成、SQLite导入及手动补导入入口已删除，没有重新开启这些流程的配置开关。服务器旧数据文件不会自动删除，旧高级只读API不属于当前页面依赖。

接口：`GET /api/forecast-accuracy/summary`，返回最新各scope汇总、合并计数与逐曲线汇总。读取损坏文件返回503，不能当作无数据。
