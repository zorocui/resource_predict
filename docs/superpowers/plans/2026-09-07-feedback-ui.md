# 校准反馈页面实施与验收

用户同意更新页面，沿用现有资源工作台布局，使用 frontend-design 技能完善详情展示；策略默认关闭。

1. 新增资源详情“校准与验证”分区：策略状态、上界完整性、原/影子分配对照、启用判定、逐指标失败原因与规则。
2. 新增只读 GET /api/resources/<id>/feedback：按资源 scope 读取报告，mtime+文件长度缓存和资源索引避免每次解析万资源报告；不加载 raw 历史，不返回全 scope 的其他资源数据，不触发评分或执行。
3. 指标图新增可由图例切换的校准上界，保留 null 断点，不用平滑或聚合抹掉样本缺失。
4. 旧产物/缺报告/过期/请求失败明确显示；未有数据不补造结果。新增 API 缓存与读取回归、Node 页面状态和转义验证，浏览器检查实际页面。
5. 本地服务只绑定 127.0.0.1:5000，不启动后台采集。运行全套 Python 验证和 JS 检查，清理缓存并保留页面供用户查看。
