# 真实误差校准上界（观察阶段）

用户同意继续实施上一轮推荐的优化：用真实偏差计算预测上界，先随建议输出并验证覆盖率。现有未提交的第二轮回填功能是本轮基础，保留其全部改动。

- 输入：每个 scope 的真实误差账本，必须是预测生成前已评分且目标时间不晚于当前数据截止的样本。按资源、容器、指标、模型、版本、配置、规格和口径隔离。
- 提前量分四段：0–1h、1–6h、6–24h、>24h。同一目标时间选择最后发布的可比预测，最多最近 500 个目标，至少 60 个。
- 计算：将 actual-predicted 排序，取第 ceil((n+1)*0.95) 项并下限截为 0；upper=当前入选预测+余量。不将上界截断为 100%。95% 是经验校准目标，时序相关及漂移下不承诺统计覆盖保证。
- 样本不足逐点 upper=null，状态 insufficient_samples/partial；数据来源缺失、账本异常有明确状态。既有 action、confidence、target_spec 和执行门控不受影响。
- 输出：图表 calibration 保存对齐上界、余量、样本数量、样本摘要与时间范围；建议 prediction_upper_bound 给出上界峰值、完整性和观察模式。规格变化后不能将旧上界解释为新规格下的结果。
- 上界和参数随原预测留档，SQLite 新增 calibrations/upper_bounds 表，兼容旧数据库；后续真实评分报告增加覆盖率、平均超出幅度和平均余量。旧留档无上界时不补造覆盖记录。
- 用单次只读快照、索引查询和限量结果控制内存。汇总仍遍历保留期账本，需在生产规模度量耗时。

验收：泄漏隔离、模型/规格/容器隔离、重复目标去重、缺样本降级、非负余量、上界留档和未来评分、增量合并和详情 API 保留字段。执行全套回归及静态检查，清理缓存。本轮不新增页面，不改变规格目标。
