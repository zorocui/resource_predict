# 未来预测辅助色带有效边界设计

## 背景

资源详情图使用橙色 `markArea` 标识未来预测阶段。当前预测曲线与辅助色带使用不同的数据有效性口径：

- 预测曲线通过 `toPairs()` 将时间和值按下标配对，并过滤时间或值为非有限数的点；
- 橙色辅助色带直接取原始 `x_pred_ms` 的第一个和最后一个时间。

因此，当未来预测序列的首部或尾部存在 `null`、`NaN`、`Infinity` 等无效值时，曲线会丢弃对应点，色带却仍覆盖原始计划窗口，造成边界与可见预测线错位。

## 目标

- 橙色未来预测区从第一个有效未来预测点开始，到最后一个有效未来预测点结束。
- 色带边界只使用 `x_pred_ms + preds_future`；测试/回测数据 `x_test_ms + preds` 不参与计算，橙色区域不得覆盖测试阶段。
- 多模型同时展示时，色带覆盖所有可见模型有效未来预测点的时间并集。
- 中间缺失点只影响曲线连续性，不把未来预测区拆成多段。
- 没有足够有效点形成时间区间时，不显示橙色区域。

## 非目标

- 不改变预测算法、预测产物结构或接口字段。
- 不改变历史线、测试线、阈值辅助线和底部时间缩放的行为。
- 不为每个预测模型分别绘制色带。
- 不处理或填补缺失预测值。

## 方案

在 `static/js/charts.js` 中增加一个独立的未来预测有效边界计算函数。函数接收 `x_pred_ms` 和 `preds_future`，对每个模型执行以下处理：

1. 按数组下标将时间和值配对；
2. 对时间执行现有的秒/毫秒归一化；
3. 只保留时间和值均为有限数的点；
4. 汇总所有模型的有效时间；
5. 返回最早和最晚有效时间。

只有当最早时间严格小于最晚时间时才创建 `markArea`。这意味着零个或一个有效未来点不会产生零宽色带。

多模型采用时间并集边界，而不是仅依赖最佳模型。图例中所有预测模型默认均可见，辅助色带应覆盖当前图表实际能够展示的全部未来预测范围。若模型有效范围不同，色带从任一模型的最早有效点延伸到任一模型的最晚有效点。

测试预测 `preds` 虽然与未来预测 `preds_future` 绘制在同一条模型曲线上，但它只用于回测展示。有效边界函数不接收 `x_test_ms` 或 `preds`，因此测试点及其缺失情况均不会改变橙色色带；色带只覆盖未来预测部分。

## 数据流

```text
x_pred_ms + preds_future
          │
          ▼
按模型、按下标配对时间和值
          │
          ▼
过滤无效时间和值
          │
          ▼
汇总所有模型有效未来时间
          │
          ▼
最早时间 < 最晚时间 ──是──> 生成橙色 markArea
          │
          否
          ▼
不生成未来预测色带
```

## 缺失点语义

- 首部缺失：色带起点收缩到第一个有效预测点。
- 尾部缺失：色带终点收缩到最后一个有效预测点。
- 中间缺失：色带仍连续覆盖首尾有效点；预测线按现有行为跳过无效点。
- 不同模型缺失范围不同：取全部模型有效点的时间并集边界。
- 全部缺失或仅一个有效点：不显示色带。
- 时间数组和值数组长度不同：只检查能够按同一索引配对的部分，不移动或补齐数据。

## 测试

新增或扩展 JavaScript 单元测试，至少覆盖：

1. 首部缺失时起点取第一个有效点；
2. 尾部缺失时终点取最后一个有效点；
3. 中间缺失不改变首尾有效边界；
4. 多模型有效范围不同，返回时间并集；
5. 全部缺失时不生成边界；
6. 仅一个有效点时不生成可绘制区域；
7. 完整数据保持当前首尾边界。
8. 测试数据早于未来预测数据且包含有效或缺失点时，色带起点仍为第一个有效未来预测点，不覆盖测试阶段。

浏览器验证使用实际资源详情图，确认橙色区域与可见未来预测线的首尾时间一致，并确认阈值线、缩放控件及 VM/K8S 图表未出现回归。

## 风险与控制

- `null` 经 `Number(null)` 会变成 `0`，不能直接沿用当前 `toPairs()` 对原始 JSON 值的宽松转换。有效边界函数必须先显式排除 `null`、`undefined` 和空字符串，再做数值有限性判断。
- 某个模型完全无有效未来点时，只忽略该模型；其他模型仍可决定色带范围。
- 该变更只影响辅助色带边界，不改变曲线数据，以控制回归范围。
