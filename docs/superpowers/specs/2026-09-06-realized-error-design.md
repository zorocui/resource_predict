# 历史预测真实误差回填

延续上一任务已提出、用户要求继续的下一步优化：用后来到达的真实监控数据评分当时留档的预测。

## 契约

- 按 scope、批次、资源、容器、指标、目标毫秒时间戳标识预测。只评入选曲线，不重算历史预测，不声称比较所有候选。
- K8S provider 在填补前保留真实 Prometheus 采样的同频聚合值；通过 observation_evidence 显式声明采样证据及规格快照。旧 raw、mock 和未提供证据的自定义 provider 不自动认定为真实观测。
- 精确时间匹配，非有限值、填补点、未到目标时间、预测生成时目标已过去、规格/口径不一致均不计分。数据截止提前量和实际发布时间提前量分别记录。
- 标准库 SQLite 按 scope 保存导入批次、原始曲线与逐点评分，唯一约束保证幂等，首次真实评分不可被后来的修订覆盖。未评分点可以在后续批次补评。
- 导入只读取尚未导入的 gzip 留档；单资源/曲线流式处理，使用索引定位待评预测，不加载所有资源历史。账本保留期与 archive_retention_days 一致；清理在评分后执行。
- 自动路径覆盖 raw 提交和预测留档；提供模块命令重试。账本失败记录日志与状态，不使已经提交的 raw 或预测失效。原始证据随 raw 分片保存用于重试，但仅保留最近接收批次，不能保证跨多个失败批次恢复。
- JSON 报告按模型、指标、容器层级和提前量分组，输出 MAE、RMSE、低估比例、低估幅度和覆盖状态；逐点记录在 SQLite 中可追溯。数据库空闲页复用，不每轮 VACUUM。

## 边界

本阶段不做概率校准、不接入 UI、不改变真实扩缩容门控。K8S 规格是拉取时快照，不能证明整段历史规格恒定；遇到历史规格变化应使用具备历史规格证据的输入。评分为同口径归一化指标误差，不等同于节省费用。

## 验收

测试时间匹配、容器隔离、重复运行、迟到补评、无证据跳过、填补排除、非有限值、规格变化、提前量、事务失败、保留期、采集到回填链路。执行全套 compileall、pyflakes、vulture 和 pytest；清理项目缓存。
