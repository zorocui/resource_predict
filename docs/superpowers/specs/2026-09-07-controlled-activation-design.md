# 按资源受控启用校准建议

用户已明确选择：实现受控启用能力，默认关闭，本次不在生产启用。

- DecisionConfig 新增 calibrated_advice_enabled=false 与 calibrated_advice_resource_ids=()，代码级配置；必须同时开启并明确选中资源才生效，不新增自动选择或批量启用入口。
- 正式建议只有在本轮完整新预测、影子 paired、留档及最新报告成功且对应同一批次、资源的启用判定有效时才切换。重建完整候选建议，核对 action/target_spec/policy_tier 与冻结影子快照一致，不能只替换 target_spec 而保留旧 confidence。
- 保存原完整建议以便回退；配置关闭/移出列表、局部或非新预测、判定失效、数据/口径/策略配置变化、读取异常时使用原策略，不延续旧校准建议。
- 切换发生在 action_gate 跨轮次确认之前；基线/校准切换或策略配置变化均重置确认计数。现有 confidence、data_quality、cooldown、policy_tier 等执行门控继续生效。
- 校准建议带评审批次、报告路径、有效期、原规格/口径摘要、策略配置摘要和原建议。入队前及开始执行前复核配置、来源匹配及判定时效；失效拒绝执行，要求重新预测。手工明确覆盖目标仍走现有手工操作规则，不将确认动作等同于校准授权。
- 不在本任务中实际开启配置、创建执行任务、修改生产规格或部署。输出/文档明确区分影子对照、评审与已采用校准建议。

验收：默认不变、未列入拒绝、有效启用、报告旧/失效/错误回退、当前候选不匹配回退、完整 confidence 重建、跨策略确认重置、执行入口失效拒绝以及旧数据不越权。全量回归、静态检查和缓存清理。
