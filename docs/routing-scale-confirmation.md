## 固定判断方式

本轮不擅自设定业务允许的精度退化比例；业务容差尚未给定，不能声明达到生产要求。
按每个指标分别给出结论，不将不同尺度的 RMSE 相加。

1. 数据完整性：快照未变，效果评分无缺失；有缺失则先记证据不足。
2. 比快速基线：分别检查四项指标的 RMSE 和 MAE；两类内存应同时改善，CPU 应不劣于快速基线，
   才记为“本次点估计达到基本预测目标”。这是描述性筛选，不是统计非劣效证明。
3. 比全部增强：估算计算成本更低，同时报告每个指标牺牲的误差；没有预设容差，不自动判断可接受。
4. 比原路由：同时报告额外耗时与各指标误差变化。内存更好但 CPU 更差、或花费更多时明确记为取舍。
5. 预算：报告逐批实际追加成本超预算次数；仍是阶段代理和名义预算，不声称硬上限。
6. 不根据新结果改变主要候选、预算比例或排除效果差的资源。失败也保留；未来修改方法须另留新数据。

满足上述方向只支持继续研究；若要声称长期泛化、实际 CPU 节省或 SLA 改善，
仍需多个未见时间区间、真实完成时刻和业务实验。本协议不涉及自动执行调配。
